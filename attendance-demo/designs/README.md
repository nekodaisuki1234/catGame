# day. デザイン候補

公開URL: https://nekodaisuki1234.github.io/catGame/attendance-demo/designs/

社員は架空の田中花子1人。2026年10月27日の固定サンプルと前日1日分だけを使います。勤務前・勤務中・退勤後の表示を、全候補で同じ内容に切り替えられます。各ページの「画面だけ見る」で比較用メニューを隠し、実際の画面に近い状態でも見られます。

- A. Paper: 余白のある手帳（a-paper.html）
- B. Studio: 文字が主役のエディトリアル（b-studio.html）
- C. Soft: やわらかな北欧調（c-soft.html）。時計は午前・午後つきの12時間表示と24時間の補助表示。5〜11時は朝、11〜16時は昼、16〜19時は夕方、19〜翌5時は夜として、時計の円だけ色が変わります。時間帯サンプルは朝08:57・昼14:35・夕方18:04・夜21:12に打刻・記録ごと切り替わります。分を示していた外周の点は廃止し、目盛りは装飾として残しています。
- D. Grid: 白とコバルトのグリッド（d-grid.html）
- E. Night: 半円と四分円のナイトポスター（e-night.html）

候補画面のサンプル編集は、本体の保存データには反映されません。サンプル編集は専用のsessionStorageキー day-design-studies-v1 に保存し、比較ページ内だけで引き継ぎます。実際の現在時刻・社員・勤務実績ではありません。

候補は共通の studies.css / studies.js を使用。Nightの幾何学アートは同梱の night-art.svg です。色だけでなく、時計と日付の構図、書体、角丸、区切り、余白を切り替えています。外部フォント・画像・ライブラリは不要です。

実際のJavaScriptを軽量DOM上で実行し、5案の共通データ、状態切り替え、手入力、休憩プリセット、打刻の上書き、別案への引き継ぎ、サンプル保存の分離を確認しました。ブラウザ・実機での目視確認は未実施です。

出勤・退勤ボタンは、記録後も押すと表示中の時刻で同じ項目だけを上書きします。出勤前の退勤は無効です。B・D・Nightには取消や確認ダイアログはありません。時刻・休憩の整合性が合わない場合や保存失敗では、元の記録を保持します。

A・Cのみ、出勤打刻・退勤打刻・取消の3ボタンです。打刻は現在時刻で上書きし、取消は当日の出勤と退勤を両方未打刻に戻します。休憩合計・表示中の時計・前日の記録は保持します。確認ダイアログはありません。休憩欄を編集中に取消しても入力中の値を保持し、別途保存できます。時刻入力は中央寄せ、押下時は短く沈む反応にし、動きを減らす設定では移動を抑止します。本体とB・D・Nightの打刻操作は変更しません。
