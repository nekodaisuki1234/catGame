# day. 勤怠アプリの操作モック

スマートフォン向けの勤怠アプリを、架空の社員50名で試せるモックです。

公開URL: https://nekodaisuki1234.github.io/catGame/attendance-demo/?v=live1

## 試せること

- 社員: 出勤・退勤・休憩、今日の出勤・退勤の取り消し、日付ごとの入力と修正、休み・有休の記録、月ごとのリスト／カレンダー表示、Excel出力。
- 勤怠タブ: 1日〜月末まで全日を表示。未入力や休み、未来の日付を含めて確認でき、今日までの日付を編集できます。
- 勤怠タブのExcelは表示中の月を全日出力します。メニューのExcelと管理者の集計は、設定した締め期間を使用します。
- 管理者: 50名の集計、氏名・所属・未入力での検索、社員別の記録確認、Excel一括出力。
- 締め日: 管理者が次回からの変更を予約。現在と過去の対象期間を保持し、移行後最初の期間をプレビュー。
- Excel: 社員用の勤怠表、管理者用の社員別集計と日別明細を .xlsx で生成。

## データと前提

ホームは「今日の勤怠」と現在の状態を先に表示します。全画面を青みのあるオフホワイト、落ち着いた紺、淡いブルーグレーの配色にまとめています。月・太陽のイラストは外し、日付・大きな現在時刻・罫線と実績グラフを中心にしています。挨拶は省き、日付・状態・打刻を優先します。現在時刻は時・分・秒を毎秒更新し、次の主操作を落ち着いた紺の塗りで強調します。月一覧・編集・管理者画面も文字、余白、ボタンを共通のスタイルにまとめています。
出勤前は「出勤」、勤務中は「退勤」、休憩中は「休憩を終える」を主操作にします。出勤・退勤は同じ位置で「打刻」と「取り消し」を切り替えます。別枠の取消リンクは置きません。未出勤時の退勤や、関連記録がある出勤取消は無効にし、理由を添えます。休憩中の退勤は引き続き操作できます。打刻時の日時は日本時間で記録します。
取り消しだけ確認画面を挟み、キャンセルでは記録を変更しません。退勤取消は出勤・確定済み休憩・メモを保持して勤務中へ戻します。退勤・休憩・メモが残る間は出勤取消を拒否し、関連記録をまとめて削除しません。単独の出勤取消は打刻前の休み／有休を復元し、履歴がない場合は未打刻に戻します。日付・社員・記録が確認中に変わった場合は実行しません。
打刻はlocalStorageへの保存成功後に記録を画面へ反映し、出勤／退勤の成功時は同じボタン内にチェックと完了メッセージを650ms表示します。演出・切り替え中は打刻と取消をロックします。保存失敗時は元の記録を保持し、成功演出を出さず再操作できるエラーにします。表示復帰時は現在時刻と過ぎた演出期限に追従します。
今日の打刻を未入力のお知らせより先に配置しています。ホームでは、実記録による今日のタイムラインと今週7日間の実働グラフを表示し、日付から既存の修正画面を開けます。
休憩の開始・終了を打刻すると、その区間を保存してタイムラインの空白に反映します。過去データや手入力の休憩合計に時刻情報がない場合、区間を推測せず注記し、時間帯を破線で表示します。勤務時刻や休憩合計を手修正すると区間情報を再推測しません。メモのみの修正では区間を保持します。
未入力・要確認の注意色は落ち着いたモーブ系を使用します。
未打刻の「今日の流れ」は見出しと状態の1行にまとめ、出勤すると実際のタイムラインを表示します。
今週の棒は実働のある日だけ描画し、休み・有休・未入力・当日未打刻・未来を文字と形で区別します。未来は編集できません。
記録の確認・修正と集計は各タブから引き続き利用できます。
新しいサンプルは当日未打刻から始まり、過去分のみ自動生成します。出勤予定日は平日として扱います。
既にブラウザに保存した記録は保持します。
変更は `day-attendance-app-v1` キーでブラウザのlocalStorageに保存します。
社員・管理者の切り替えはデモ表示用で、本番の権限制御ではありません。
Microsoftログイン、SharePoint、SQLなどの実データには接続していません。
残業や休暇残数などの就業ルールは未設定です。
Excelは仮レイアウトです。既存の勤怠表テンプレートへの対応は、実物の確認後に実装する想定です。

## 構成

- `index.html`: 画面とダイアログ
- `styles.css`: スマホ中心のレスポンシブ表示
- `model.js`: 勤怠・締め期間・サンプルデータ・XLSX生成
- `app.js`: 画面遷移と操作

外部のライブラリや画像配信サービスに依存しません。

## 確認

再読み込み後の表示、日付またぎ、休憩、月一覧／カレンダー、Excel、管理者集計を確認しました。
