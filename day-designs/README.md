# day. デザイン候補

公開URL: https://nekodaisuki1234.github.io/catGame/day-designs/

社員は架空の田中花子1人。B〜Eは2026年10月27日の固定サンプルと前日1日分だけを使います。Aは旧勤怠アプリの機能を追加した独立した操作デモです。勤務前・勤務中・退勤後の表示を、全候補で同じ内容に切り替えられます。各ページの「画面だけ見る」で比較用メニューを隠し、実際の画面に近い状態でも見られます。

- A. Paper: 余白のある手帳（a-paper.html）。下記の勤怠機能を追加しています。
- B. Studio: 文字が主役のエディトリアル（b-studio.html）
- C. Soft: やわらかな北欧調（c-soft.html）。時計は午前・午後つきの12時間表示と24時間の補助表示。5〜11時は朝、11〜16時は昼、16〜19時は夕方、19〜翌5時は夜として、時計の円だけ色が変わります。時間帯サンプルは朝08:57・昼14:35・夕方18:04・夜21:12に打刻・記録ごと切り替わります。分を示していた外周の点は廃止し、目盛りは装飾として残しています。
- D. Grid: 白とコバルトのグリッド（d-grid.html）
- E. Night: 半円と四分円のナイトポスター（e-night.html）

候補画面のサンプル編集は、本体の保存データには反映されません。以下の共通サンプル保存・固定時刻の説明はB〜Eに適用します。サンプル編集は専用のsessionStorageキー day-design-studies-v1 に保存し、比較ページ内だけで引き継ぎます。実際の現在時刻・社員・勤務実績ではありません。

候補は共通の studies.css を使用。B〜Eの動作は studies.js、Aの動作は専用の paper-core.js / paper-app.js と追加の paper.css を使用。Nightの幾何学アートは同梱の night-art.svg です。色だけでなく、時計と日付の構図、書体、角丸、区切り、余白を切り替えています。外部フォント・画像・ライブラリは不要です。

実際のJavaScriptを軽量DOM上で実行し、5案の共通データ、状態切り替え、手入力、休憩プリセット、打刻の上書き、別案への引き継ぎ、サンプル保存の分離を確認しました。ブラウザ・実機での目視確認は未実施です。

## 独立配置

このフォルダは単独で配置できます。index.html と5つの候補HTML、studies.css、studies.js、night-art.svg、paper.css、paper-core.js、paper-app.js を同じ階層に置いてください。アプリ本体へのリンクは絶対URLを使用しています。

元の候補一覧（attendance-demo/designs/）も引き続き利用できます。catGameを含まないホスト名への切り替えには、別のGitHub Pagesリポジトリ等の公開先設定が必要です。

出勤・退勤ボタンは、記録後も押すと表示中の時刻で同じ項目だけを上書きします。出勤前の退勤は無効です。B・D・Nightには取消や確認ダイアログはありません。時刻・休憩の整合性が合わない場合や保存失敗では、元の記録を保持します。

A・Cのみ、出勤打刻・退勤打刻・取消の3ボタンです。Aでは取消と同時に当日の工数も0に戻します。打刻は現在時刻で上書きし、取消は当日の出勤と退勤を両方未打刻に戻します。休憩合計・表示中の時計・前日の記録は保持します。確認ダイアログはありません。休憩欄を編集中に取消しても入力中の値を保持し、別途保存できます。時刻入力は中央寄せ、押下時は短く沈む反応にし、動きを減らす設定では移動を抑止します。本体とB・D・Nightの打刻操作は変更しません。

## A. Paper の勤怠機能

対象はこのフォルダの `a-paper.html` のみです。Paperの背景色・書体・時計・打刻の3ボタンと罫線を保ち、旧アプリの項目を同じスタイルに配置しました。共有CSS/JS、B〜E、アプリ本体、旧配置 `attendance-demo/designs/` は変更していません。

- ホーム：日本時間の現在時計、出退勤の上書き打刻、時刻の直接入力、翌日退勤、休憩、勤務場所・作業内容の自動保存。
- 詳細：勤務実績、有休・半休・公休・特別休暇、P1〜P4・SETの工数。工数は時間単位で入力し、配分時は実働との一致を検証します。0のままの未配分も保持できます。
- 勤怠：月別グラフ、1日〜月末の一覧、日別修正、今週の実働、月別Excel出力。未来の日付は編集できません。
- 提出：前月16日〜当月15日・前月末・当月末の3期間、今日までの未入力と退勤未入力の確認、未入力日への移動、Excel出力とテスト提出履歴。記録を修正すると、その日を含む期間の履歴を未提出に戻します。
- 設定：新しい日の初期場所・作業内容・休憩、基準時間の下限・上限、勤務予定、作業概要、PJ1〜4の略称・概要、場所1〜3の名称・住所。PJ・場所を切り替えても更新前の入力を保持します。

保存先はA専用のlocalStorageキー `day-paper-attendance-v1` です。他案のsessionStorageと本体のデータは読み書きしません。初回は画像に対応した2026年4〜10月の架空の履歴を表示し、当日は未打刻から始めます。過去の履歴を自動で追加・補完することはありません。状態ボタンは今日の記録をサンプル値に上書きし、その間だけ時計を固定します。「現在時刻に戻す」で時計を戻せます。

この実装は操作デモです。旧アプリからのデータ移行、本人認証、端末間同期、実メール送信には接続していません。事前確認送信オンは「テスト提出済」、オフは「出力済」として端末内に記録し、どちらも実送信済とは表示しません。Excelは日別の休憩・実働・場所・作業内容・工数と、PJ/作業場所の設定を2シートに出力します。

検証：`node tests/paper-attendance-check.cjs`。日付・月跨ぎ、日本時間、時刻・休憩・工数の整合性、休暇、期間、未入力、保存データ、Excel ZIP/CRCを検証します。Chromiumで打刻・編集・保存と再読み込み・保存失敗・全タブ・日別修正・設定切替・提出確認とダウンロードを操作し、320/390/430/1280pxで横はみ出しがないこととAの書体・基本色の一致を確認しました。ダウンロードしたExcelのXMLも解析済みです。


### 勤務実績・警告・打刻の更新

勤務実績は月間予定の達成リング、実績と残り時間、本日・勤務日数・年度有給の指標、PJ別の積み上げバーと個別バーを表示します。Aの生成り・紺・青緑の書体と配色を引き継ぎます。

休憩を引いた実働がマイナスでも保存を拒否せず、符号付きの時間を日別・週次・月次に表示します。保存後の警告は7秒間のトーストで表示し、画面内に警告欄を追加しません。操作や入力フォーカスを妨げず、自動で消えます。時刻・休憩を変更した場合だけ警告し、作業内容だけの保存では繰り返し表示しません。既存の工数は保持し、実働がマイナスの間は工数との合計一致を保存条件にしません。不正な時刻や入力範囲、保存失敗の検証は維持しています。Excelでは負の時間を文字列で出力し、Excelの負の時刻表示による文字化けを避けます。

出退勤の保存成功時だけ、同じサイズのボタンでチェック描画・短いバウンド・光の通過を表示し、850ms後に通常表示へ戻します。保存失敗時には成功表示を出しません。動きを減らす設定では動かさずチェックを表示します。

### 勤怠一覧からの日別編集

日付の編集はダイアログではなく、Aデザインの専用画面です。前日・翌日・カレンダーで日付を選び、出社時間・退社時間・休憩時間（hh:mm）・自動計算の勤務時間・休日設定・勤務場所・作業内容・P1〜P4/SETの順で入力します。休憩は候補の選択と分単位の手入力に対応します。工数の合計が実働に一致すると「振り分け完了」と表示します。更新後も同じ日の編集画面に留まり、保存結果をトーストで表示します。日付の切替やタブ移動では更新前の入力を画面内で保持し、未来の日付は選べません。勤怠一覧・ホーム・提出確認へ戻る操作も用意しています。
