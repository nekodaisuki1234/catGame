# day. 勤怠アプリの操作モック

スマートフォン向けの勤怠アプリを、架空の社員50名で試せるモックです。

公開URL: https://nekodaisuki1234.github.io/catGame/attendance-demo/?v=two-colors1

## 試せること

- 社員: 出勤・退勤、1日の合計休憩時間の入力、今日の出勤・退勤の取り消し、日付ごとの入力と修正、休み・有休の記録、月ごとのリスト／カレンダー表示、Excel出力。
- 勤怠タブ: 1日〜月末まで全日を表示。未入力や休み、未来の日付を含めて確認でき、今日までの日付を編集できます。
- 勤怠タブのExcelは表示中の月を全日出力します。メニューのExcelと管理者の集計は、設定した締め期間を使用します。
- 管理者: 50名の集計、氏名・所属・未入力での検索、社員別の記録確認、Excel一括出力。
- 締め日: 管理者が次回からの変更を予約。現在と過去の対象期間を保持し、移行後最初の期間をプレビュー。
- Excel: 社員用の勤怠表、管理者用の社員別集計と日別明細を .xlsx で生成。

## データと前提

ホームは「今日の勤怠」と現在の状態を先に表示します。全画面を青みのあるオフホワイト、落ち着いた紺、淡いブルーグレーの配色にまとめています。月・太陽のイラストは外し、日付・大きな現在時刻・罫線と実績グラフを中心にしています。挨拶は省き、日付・状態・打刻を優先します。現在時刻は時・分・秒を毎秒更新し、出勤は紺色、退勤は落ち着いた青緑で色分けし、記録後もそれぞれの色を保ちます。月一覧・編集・管理者画面も文字、余白、ボタンを共通のスタイルにまとめています。
出勤前は「出勤」、勤務中は「退勤」を主操作にします。出勤・退勤は同じ位置で「打刻」と「取り消し」を切り替えます。打刻後は成功演出・切り替え中・再表示後も出勤と退勤それぞれの色を保ちます。記録がある間は、ボタン内に「出勤 10:09」「退勤 18:02」のように記録時刻を常時表示します。別枠の取消リンクは置きません。未出勤時の退勤や、関連記録がある出勤取消は無効にし、理由を添えます。打刻時の日時は日本時間で記録します。
打刻の取り消しは確認画面を挟まず、1タップで保存して即時反映します。退勤取消は出勤・確定済み休憩・メモを保持して勤務中へ戻します。退勤・過去の休憩区間・メモが残る間は出勤取消を拒否し、関連記録をまとめて削除しません。合計時間だけの休憩は、出勤取消後もその日の入力値として残します。単独の出勤取消は打刻前の休み／有休を復元し、履歴がない場合は未打刻に戻します。日付や社員が変わった古い画面からは実行しません。
打刻はlocalStorageへの保存成功後に記録を画面へ反映し、出勤／退勤の成功時は記録時刻を保ったまま、同じボタン内にチェックと「10:09に出勤しました」のような完了メッセージを650ms表示します。チェック表示650msとラベル切り替え140msの計約790msの間は、同じ位置の打刻・取消だけをロックします。保存後は時刻欄・休憩変更・もう一方の打刻を操作でき、実際の保存中だけ関連の変更を抑止します。成功演出の切り替えは打刻ボタン部分だけを更新し、編集中の時刻欄・休憩欄とフォーカスを保持します。別の保存や取消を行った後は、古い演出のタイマーが新しい記録や入力を更新しません。保存失敗時は元の記録を保持し、成功演出を出さず再操作できるエラーにします。表示復帰時は現在時刻と過ぎた演出期限に追従します。
ホームの出勤・退勤ボタンは現在時刻を1タップで記録します。時刻欄の上には初期画面から「時刻は手入力・修正できます」と「自動保存」を表示します。時刻欄の文言は記録ごとに切り替え、未記録なら「出勤時刻を入力」「退勤時刻を入力」、記録済みなら「出勤時刻を編集」「退勤時刻を編集」と表示します。直接編集の自動保存後も、入力欄を作り直さず文言とアクセシブル名を更新します。時刻欄は淡い背景・薄い枠・控えめな角丸の入力ボックスに整えています。外側にパネルは追加せず、両列の幅・高さ・余白をそろえ、フォーカス時に枠と背景を強調します。すぐ下の出勤／退勤時刻欄は、入力欄を直接タップして時刻を選べます。時刻の変更確定時に自動保存するため、別の編集画面への移動や保存ボタンは必要ありません。出勤前でも出勤時刻を手入力でき、出勤後は退勤時刻も手入力できます。手入力でも同じ休憩合計・勤務時間の検証を使い、集計を更新します。「翌日に退勤」で日付をまたぐ退勤時刻も入力できます。未記録の時刻を仮の値で埋めず、空欄への変更で取消を代用しません。時刻と関連のない休憩合計・メモは保持し、保存失敗では元の記録を残します。ネイティブの時刻選択UIが対応している環境ではshowPickerを使い、非対応環境では標準入力へ戻ります。時刻変更で入力欄自体を描き直さず、フォーカスを保ちます。変更確定直後の250msだけ打刻・取消ボタンを抑止し、編集を確定したタップで誤って取り消すことを防ぎます。時刻欄の連続編集は妨げません。画面復帰時には期限切れの抑止を解除します。
今日の打刻を未入力のお知らせより先に配置しています。「今日の流れ」と休憩区間のタイムラインはホームから外し、日次休憩の合計と今週7日間の実働グラフを表示します。日付から既存の修正画面を開けます。
休憩の開始・終了打刻は廃止し、新しい勤務日は1時間00分をそのまま使います。ホームは保存済みの合計と「変更」だけを表示し、変更するときだけ時間・分の入力欄と「保存」を開きます。変更をやめると入力中の値を破棄し、保存済みの合計に戻します。既存の0分・60分・90分などはそのまま引き継ぎます。ホームと日別編集は共通の0・30・45・60・90分プリセットを使い、選ぶと時間・分を一緒に更新します。選択後は従来どおり「保存」で確定し、「やめる」では記録を変えません。休憩を入力中に出退勤を押した場合も入力値と打刻を一緒に保存します。出勤前の値は社員・日付別のbreakDraftsに保存し、勤務記録を作った後はbreakMinutesを使います。実働は出退勤の差から合計休憩を控除し、勤務中は0未満にしません。退勤確定時と確定済み記録の編集時は勤務の時間幅を超える休憩を拒否します。ホームの超過エラーには「休憩時間を変更」を表示し、その場で既存の休憩入力欄を開けます。翌日退勤の記録にも適用します。
既存の休憩合計を変更せず移行し、開始中だった旧休憩は保存されている合計で固定します。終了時刻を推測して加算しません。既存の休憩区間は合計と勤務時刻が変わらなければデータとして保持します。画面では1日の休憩合計を扱い、休憩の時間帯は表示しません。勤務時刻や休憩合計の修正では区間を再推測しません。
未入力・要確認の注意色は落ち着いたモーブ系を使用します。
今週の棒は実働のある日だけ描画し、休み・有休・未入力・当日未打刻・未来を文字と形で区別します。未来は編集できません。
記録の確認・修正と集計は各タブから引き続き利用できます。
新しいサンプルは当日未打刻から始まり、過去分のみ自動生成します。出勤予定日は平日として扱います。
既にブラウザに保存した記録は保持します。
変更は `day-attendance-app-v1` キーでブラウザのlocalStorageに保存します。
社員・管理者の切り替えはデモ表示用で、本番の権限制御ではありません。
Microsoftログイン、SharePoint、SQLなどの実データには接続していません。
残業や休暇残数などの就業ルールは未設定です。
Excelは仮レイアウトです。既存の勤怠表テンプレートへの対応は、実物の確認後に実装する想定です。

## 構成

- `index.html`: 画面とダイアログ
- `styles.css`: スマホ中心のレスポンシブ表示
- `model.js`: 勤怠・締め期間・サンプルデータ・XLSX生成
- `app.js`: 画面遷移と操作

外部のライブラリや画像配信サービスに依存しません。
